# 📝 Exercíses JavaScript

Este repositório contém soluções para uma série de exercícios de JavaScript, abrangendo desde funções básicas até manipulação de arrays e objetos.

## 🔍 Exercises

Cada questão é resolvida em um arquivo JavaScript separado e documentada abaixo:

### 🔢 Exercises Resolvidas

1. ✏️ **Função `soma`:** Recebe dois parâmetros (a e b) e retorna a soma deles.
2. ✅ **Função `isPar`:** Recebe um número inteiro e retorna "true" se o número for par ou "false" caso contrário.
3. 📊 **Função `media`:** Recebe três notas e retorna a média aritmética delas.
4. ⚖️ **Função `imc`:** Recebe o peso (kg) e altura (m) de uma pessoa e retorna o índice de massa corporal (IMC).
5. 🛒 **Função `calcularDesconto`:** Recebe o valor de um produto e o percentual de desconto, retornando o valor com desconto aplicado.
6. 💰 **Função `calcularImpostoRenda`:** Calcula o imposto de renda com base no salário bruto, considerando diferentes faixas de renda:
   - Até R$ 1.903,98: isento
   - De R$ 1.903,99 até R$ 2.826,65: alíquota de 7,5%
   - De R$ 2.826,66 até R$ 3.751,05: alíquota de 15%
   - De R$ 3.751,06 até R$ 4.664,68: alíquota de 22,5%
   - Acima de R$ 4.664,68: alíquota de 27,5%
7. 🔄 **Função `calcularMediaArredondada`:** Recebe uma lista de números e retorna a média aritmética arredondada.
8. 🔢 **Função `contarDigitosParesImpares`:** Conta os dígitos pares e ímpares de um número inteiro.
9. 🎓 **Função `calcularMediaAlunos`:** Recebe uma lista de alunos (nome e nota) e calcula a média das notas.
10. 🎂 **Função `calcularIdade`:** Recebe o ano de nascimento e retorna a idade atual.
11. 🧮 **Função `gerarTabuada`:** Recebe um número e exibe a tabuada de 1 a 10 no console.
12. 🔍 **Função `advinheNumero`:** Gera um número aleatório entre 1 e 100 para o usuário adivinhar, com dicas de maior ou menor.
13. 🔑 **Função `verificarPropriedade`:** Verifica se um objeto possui uma propriedade especificada.
14. 💸 **Função `calcularPrecoProduto`:** Calcula o preço de venda de um produto com base no custo, margem de lucro e frete.
15. 📝 **Função de String Mais Longa:** Encontra a palavra mais longa dentro de uma string.
16. 🖼️ **Função de Quadro Retangular:** Imprime strings em um quadro retangular.
17. 🔠 **Função de Strings Longas:** Retorna strings com mais de 5 caracteres.
18. 📚 **Função de Livros por Autor:** Retorna livros escritos por um autor específico.
19. 👵 **Função de Pessoa Mais Velha:** Retorna o nome da pessoa mais velha.
20. 🚗 **Função de Carros Recente:** Retorna carros fabricados após um certo ano.
21. 🔁 **Função `inverterString`:** Inverte uma string.
